# 酷安净化

基于 LSPosed 的酷安净化模块，可隐藏广告和多类冗余内容，并在酷安设置中提供独立开关。

## 功能与默认设置

打开酷安“设置”→“酷安净化”，可分别调整以下 10 项功能：

| 功能 | 全新配置默认值 |
| --- | --- |
| 去除启动/开屏广告和全屏广告 | 开启 |
| 去除首页信息流广告与赞助卡片 | 开启 |
| 去除帖子回复区及评论中的赞助内容 | 开启 |
| 去除自动评论提示 | 关闭 |
| 去除话题与机型推荐 | 关闭 |
| 去除帖子相关推荐 | 关闭 |
| 去除同话题动态 | 关闭 |
| 去除帖子内推广 | 关闭 |
| 去除热门搜索与热榜热词 | 关闭 |
| 去除搜索页热榜 | 关闭 |

设置和适配缓存保存在酷安自己的私有目录，无需跨应用唤起模块、加入自启动或后台白名单。升级后首次打开酷安时会尝试迁移旧版 LSPosed 中的已有选择，之后以酷安本地配置为准，不再向框架数据库写入配置。

更改选项后，请强制停止酷安并重新打开；若提示“配置保存失败”，请重试。升级模块或酷安会保留设置；清除酷安数据或卸载酷安会删除本地配置。若旧版框架配置仍可读取，之后首次启动可能再次迁移旧选择。

## 兼容性

| 项目 | 要求 |
| --- | --- |
| 目标应用 | 酷安，包名 `com.coolapk.market` |
| 酷安版本 | 16.6.1（2608212）、16.6.2（2609151）、16.6.4（2609291）、16.6.5（2610162）、16.7.0（2610291）支持全部 10 项功能 |
| Android | 9.0 及以上 |
| 框架 | 支持 libxposed Modern API 102 的 LSPosed |
| 模块版本 | 2.7.0 |

开屏和首页信息流会尝试自动适配；其他功能仅在上表列出的酷安版本中启用。无法适配时会保留酷安原有显示。

## 安装与使用

1. 从 [GitHub Releases](https://github.com/yylsping/coolapk-purifier/releases) 下载并安装 APK。
2. 在 LSPosed 中启用模块，作用域只选择“酷安”。
3. 强制停止酷安后重新打开。
4. 在酷安“设置”→“酷安净化”中调整选项，按提示重新启动酷安。

模块没有独立桌面入口。“酷安净化”位于酷安原生设置列表最上方，配置页直接在酷安内打开，返回后保留原生设置的导航和状态。首次适配时可能显示一次开屏广告。

## 构建

需要 JDK 17 和 Android SDK Platform 37；模块 targetSdk 为 35。

运行单元测试并生成调试包：

```powershell
.\gradlew.bat --no-daemon testDebugUnitTest testCompatibleUnitTest testReleaseUnitTest assembleDebug
```

调试包输出到 `app/build/outputs/apk/debug/`。生成 release 包可使用 `assembleRelease`，签名配置放在本地 `signing-private/` 中。
